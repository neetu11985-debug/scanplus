Before you continue

This is for the account owner's own number only. Twilio receives your phone number and the code you enter. After separate consent, Serper receives your number for at most three Google-index queries: Spokeo, TruePeopleSearch and Whitepages, up to ten results each. This does not search the whole Internet or directly query broker databases. A possible match must be reviewed by you.

The operator must first confirm sufficient approved no-card/free allowance in both provider accounts. Maximum per operator-approved run: one SMS start, five code checks and three search attempts. Failed or uncertain requests consume the allowance too. There is no automatic retry, fallback or paid top-up. A durable allowance ledger reserves each attempt before the provider is called. Clear, reload and server restarts do not reset it. Missing or unavailable allowance blocks the request. These limits are not an account balance or a dollar spending cap. Do not proceed if paid usage could be required.

Phone/challenge and report access expire five minutes after SMS start. Server cleanup runs each second but an in-flight provider request can delay memory cleanup. The five-second transport timeout is an inactivity timeout, not a guaranteed total duration. It clears the raw phone after search. The allowance database stores only an opaque run ID, expiry and counters, never your phone, code or report. No analytics or application request log stores your input or results. Provider and hosting-platform retention are outside ScanPlus's control. Downloads may contain personal information in URLs and remain on your device after Clear or expiry. Opening a result contacts that site.

Clear removes this test's state, not the browser's private-test login. Use a private browser session and close it when finished. Restart, expiry or Clear can make the report unrecoverable.
